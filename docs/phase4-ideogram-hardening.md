# Phase 4 — Ideogram implementation note

Ideogram 4 remains implemented in the repository for possible future use, but it is not part of the
active production image-generation route. Phase 4 references and Phase 6 keyframes are generated by
Qwen-Image-2.1.

## Preserved Ideogram components

The repository keeps the Ideogram worker, provider, caption validation, deterministic safety variants,
bootstrap watchdogs and deployment configuration. These components can be evolved independently
without affecting the Qwen-only production route.

The Ideogram caption logic keeps safety-neutral location prompts and bounded deterministic variants.
Terminal safety results can still be represented by its provider-specific cache metadata when that
implementation is tested directly.

## Production boundary

The controlled Phase 4 and Phase 6 runners do not select Ideogram and do not perform automatic
provider fallback. They use the Qwen service declared in `deploy/salad/services.json`.

Any future reactivation of Ideogram should be an explicit product decision with dedicated tests and
documentation rather than an implicit fallback path.
